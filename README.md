# Домашнее задание к работе 4

## Условие задачи  
В умном коворкинге два сканера: по лицу (A) и по карте (B). Система открывает дверь, если ровно один из сканеров вернул четный код доступа (такие коды выдаются временным посетителям).  
Запишите условие открытия двери.
## 1. Алгоритм и блок-схема

### Алгоритм
1. **Начало**
2. Вывести номер варианта:
   - `printf("Номер варианта:%d\n", 30 % 20 + 1)`
4. Объявить переменные:
   - `int A, B` = A-код по лицу, B-код по карте  
   - `int condition` = переменная для проверки условия
5. Вывести заголовок:  
   - ` printf("=СИСТЕМА ДОСТУПА В КОВОРКИНГ=\n")`
6. Ввод двух кодов:  
   - `scanf("%d %d", &A, &B)`
9. Проверка условия:  
   - `condition = ((A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0))`
10. Вывести разрешение/запрет доступа:  
   - `puts("Если 1 - доступ разрешен, если 0 - доступ запрещен ")`  
   - `printf("Ваш доступ: %d", condition)`  
11. **Конец**

## 2. Реализация программы
```C++
#include <stdio.h>  
#include <locale.h>  
int main()  
{  
	setlocale(LC_CTYPE, "UTF-8");  
	printf("Номер варианта:%d\n", 30 % 20 + 1);  
    int A, B;  
    int condition;  
    printf("=СИСТЕМА ДОСТУПА В КОВОРКИНГ=\n");  
    printf("Введите два целых числа\n");  
    scanf("%d %d", &A, &B);  
    condition = ((A % 2 == 0 && B % 2 != 0) || (A % 2 != 0 && B % 2 == 0));  
    puts("Если 1 - доступ разрешен, если 0 - доступ запрещен ");  
    printf("Ваш доступ: %d", condition);  
}

```
